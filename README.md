# deepen-legal

Public legal/contact pages for the [Deepen](https://github.com/danamikita/DeepJournal) app, hosted via GitHub Pages.

No app source code lives in this repo - it exists only so Deepen's Play Store listing has a public URL for its privacy policy, since the app's own repo is private.

Live at: https://danamikita.github.io/deepen-legal/
